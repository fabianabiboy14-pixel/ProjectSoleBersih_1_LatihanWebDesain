# Sol Bersih - Website Jasa Cuci Sepatu

Landing page satu halaman untuk jasa cuci sepatu, dibuat dengan HTML dan CSS
yang dipisah menjadi berkas sendiri.

## Cara menjalankan
1. Ekstrak berkas zip proyek.
2. Buka `index.html` dengan dua kali klik, atau seret ke browser.
3. Sambungkan ke internet agar font Google Fonts muncul.

Tidak perlu instalasi apa pun.

## Struktur proyek
| Berkas atau folder | Fungsi |
|--------------------|--------|
| index.html | Struktur halaman |
| css/style.css | Tampilan dan tata letak |
| assets/images/ | Gambar yang digunakan |
| docs/requirements.md | Dokumen kebutuhan |
| docs/testing.md | Catatan pengujian |
| README.md | Petunjuk menjalankan proyek |
| CHANGELOG.md | Riwayat perubahan |

## Bagian halaman
Homepage, Keunggulan, Paket Layanan, dan Info (testimoni, FAQ, kontak).

## Yang perlu diganti sebelum dipublikasikan
Nomor WhatsApp, alamat, email, ulasan, dan angka statistik masih berupa contoh.

## Gambar
`assets/images/sepatu.svg` adalah ilustrasi buatan sendiri sehingga bebas dipakai.
Jika memakai foto, pilih yang berlisensi bebas (misalnya Unsplash atau Pexels)
dan catat sumbernya.
